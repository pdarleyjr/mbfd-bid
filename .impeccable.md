## Design Context

### Users
MBFD administrators who may not be computer savvy maintain personnel, qualifications and staffing year-round, translate approved Labor/Management changes into annual bids, and operate complex bid procedures. The user explicitly requests intuitive navigation, visible responses to clicks, collapsible sections and minimal page scrolling without losing configuration options.

### Brand Personality
Clear, dependable, professional. Preserve the existing MBFD identity and design tokens; make the administrator confident about what changed, what is saved and the next permitted action.

### Aesthetic Direction
Use the established Next.js/React, Tailwind and Base UI components. Keep work inside the available browser frame with searchable, paginated lists and focused task panels. Support desktop, narrow windows, touch and keyboard without reducing text until it is unreadable or clipping content.

### Design Principles
1. Make a click's result visible immediately, including loading, empty, error and retry states.
2. Every expanded section can collapse; every task panel can close and return focus.
3. Preserve all options through progressive disclosure, searchable details and complete exports.
4. Carry selected member/year/setup context and show the consequences of changes using authoritative calculations.
5. Preserve historical evidence, explicit operator authority and deterministic rules; visual simplicity must not weaken safeguards.
